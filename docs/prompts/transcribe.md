# Prompt · transcribe(转录原文)

> 用途:把原始资料(扫描件、影印件、电子文本)转录为 `.rt` 文件的 `source` 区段。

---

## Prompt 模板

```text
你正在按 RiverType Transliteration Protocol (RTP) v0.1 转录一段中国古籍。

# 任务

将以下原始资料逐字转录,作为 .rt 文件的 `source` 区段。

# 原始资料

<在此粘贴原始文本/OCR 文本/扫描件>

# 底本与版本

- 底本:<底本名称>
- 朝代/年代:<朝代>
- 影印来源:<如 "中华书局 1980 版第 X 页">

# 转录规则(强制)

1. **一字不改** — 包括异体字、避讳字、讹字。AI 不得"修正"
2. **保留行款** — 原文换行 / 段位尽量保留
3. **编码规范** — 异体字用 Unicode,不要造字
4. **存疑标注** — 看不清的字用 `[?]` 占位
5. **避讳字保留原字** — 如"玄"作"元"避清圣祖讳,保留"元"字

# 输出格式

严格按以下 Markdown 格式输出:

```
---
title: <书名>·<卷次>
work_id: <work_id>
author: <作者>
dynasty: <朝代>
editions:
  base: <底本>
  collated:
    - <参校本1>
    - <参校本2>
protocol: rtp/0.1
created: <YYYY-MM-DD>
transliterator: <引擎名>
---

<!-- @section: source -->
## 原文

> <第一行原文>
> <第二行原文>
> ...
```

# 反例(不要这样输出)

❌ "上善若水,水善万物而不争" — 这是白话译,不是原文转录
❌ "上善若水(水=生命的源泉)" — 加了注释,应放 annotation 区
❌ "上善若水[疑]" — 原文没有"疑"字,不要擅自添加

# 校验清单

输出前自查:
- [ ] frontmatter 9 个必需字段齐全
- [ ] 原文逐字与原始资料一致(肉眼比对)
- [ ] 异体字 / 避讳字未做"修正"
- [ ] 看不出的字用 `[?]`,没有自行补字
```

---

## 实测案例

### 输入(假设)

> 马王堆帛书甲本《老子》第一章(扫描件 OCR)
> "上善堇水水土善利萬物而不爭"

### 输出(正确)

```markdown
---
title: 道德经·第一章(帛甲本)
work_id: ddj-c01-baojia
author: 老子
dynasty: 西汉
editions:
  base: 马王堆帛书甲本
  collated:
    - 王弼本
    - 河上公本
protocol: rtp/0.1
created: 2026-09-20
transliterator: 文川院 AI v1
---

<!-- @section: source -->
## 原文

> 上善堇水。
> 水善利萬物而不爭,
> 處衆人之所惡,
> 故幾於道。
```

注意:"堇"保留(帛书甲本用字),"萬"未改"万"(繁简之别保留原文)。

---

## 失败案例

### F-1 · AI 自行简化

**输出**:"上善若水。水善利万物而不争。"(用了"若"代替"堇","万"代替"萬")

**问题**:违反"一字不改"原则。

**修正**:重发 Prompt,在开头强调:"**绝对禁止替换任何字,即使你觉得原字是错的**。"

---

### F-2 · AI 把避讳字"还原"

**输出**:把"元"改回"玄"(避清圣祖讳)。

**问题**:违反版本真实性。

**修正**:在 Prompt 中强调"避讳字保留原字"。

---

### F-3 · AI 补出脱字

**输出**:帛书有脱字处,AI 自动用 [缺字] 标注。

**问题**:标注格式应统一。建议使用 `@脱文` 注解,在 `annotation` 区说明,不直接在 source 区放 `[缺字]`。

**修正**:在 Prompt 中规定"source 区不放任何标注,所有标注放 annotation 区"。
