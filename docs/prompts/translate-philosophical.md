# Prompt · translate-philosophical(现代哲学英译中)

> 用途:把现代英语哲学 / 美学 / 人文散文(尤其含德语传统的英译本,如 Byung-Chul Han、Slavoj Žižek)译为现代汉语,带古典白话色彩。
>
> 这是 Rivertype 第三个翻译方向(与 `vernacular.md` 古汉 → 现代汉、`english.md` 古汉 → 英 并列)。
> 源:现代英语(含希腊/德/拉丁/法术语)
> 目标:现代汉语 + 古典节奏("之"、"于...之中")
> 任务密度:重学术转译,而非通俗白话

# 翻译原则(七大铁律)

## 1. 术语保留(term retention)
希腊文 / 德文 / 拉丁文 / 法文术语**原样保留**,斜体 + 中文括注。
❌ *Eros* → "爱神"  (失去术语辨识)
✅ *Eros*  **情色爱好者**(全文统一)

## 2. 概念加粗(concept emphasis)
关键概念词一律 `**bold**`,无论原版是否强调。
判断标准:此词若在文中重复出现 ≥ 3 次,且为论证支点。

## 3. 古典节奏(classical cadence)
适当使用文言连接,而非纯白话:
- "于 X 之中" 优于 "在 X 里"
- "之" 优于 "的"(用于"概念 + 之 + 概念"结构)
- "毋宁" 优于 "不如"
- "乃" 优于 "是"(用于判断句)

但**禁用**彻底文言句式("之乎者也" 不出现)。

## 4. 逐句对应(fidelity)
不增不减;不补原文"言外之意";不省略看似"重复"的句子。

## 5. 直接引文格式
用 `> blockquote` 包裹;
署名行用 `<p align="right">— 作者,出处</p>`。
原文中若作者署名已右对齐则保留。

## 6. 章节命名格式
`# 第N章 中文名`
- 中文章次:一、二、……、十四
- 中文名:从章节内容提炼,**不译**原文章节名(若原文章节名为抽象词)
- 例:`# 第七章 灾异的美学`

## 7. 译文说明块(translational preamble)
每章顶端可有:
> 译文说明:本章译自《书名》(作者,版本)。
> 译文仅供个人学习使用,请勿传播。
> 体例:正文段落 + 黑体引文保留原引用上标(脚注见文末),术语保留英文/德文原词以便对照。

EPUB 发布前**剥除**此块(用工具层处理)。

# 反例(绝对不能这样译)

❌ "Eros 是希腊的爱神"——失去术语 + 网络百科腔
❌ "在美之中发生的事件"——非古典节奏
❌ "他的艺术非常酷"——网络流行语
❌ "根据某某的理论……"——翻译腔;哲学译应当直接陈述
❌ 把德文术语 *Hervorscheinen* 译为"明显的显现"——必须保留德文
❌ 把希腊文 *tokos en kalo* 译为"以美的方式生育"——失去希腊字源

# 书名候选机制(title candidacy)

用户未定时,AI **必须**生成 5–8 个候选,跨四种风格:

1. **直译** —— 完全对应英文:留存美 / 美的拯救
2. **留存** —— 突出"留住、守住" 义:留存美 / 留住美
3. **存在论 / Heidegger 调** —— 系美于存在之真:让美存在 / 美之居留
4. **修辞 / 辩护体** —— 仿古典修辞:为美辩护 / 美的逾越

每条带一句说明,推荐其一。**不替用户决定**。

# 实测案例

### 输入(韩炳哲《Saving Beauty》第十四章首段)

```
In the Symposium, Plato sets up a gradation of beauty. The lover of beauty is not
content with the view of a beautiful body. He or she moves up the ladder beyond
ordinary beauty to the point of beauty as such. However, the inclination towards
beautiful bodies is not condemned. Rather, it is an essential part, even the
necessary initial point, of the ascent towards beauty.
```

### 输出

```
于《会饮》中,Plato 建立一美之阶梯。美之爱好者不满足于观一美之身体。
她或他沿梯而上,超出那日常之美,直至那"美自身"之处。然则,对美之身体之倾向,
并不被谴责。毋宁,它是那朝向美之攀登之必要部分——甚至必要之起始。
```

要点:

- *Plato* 拉丁拼写保留(非 *柏拉图*)
- 《会饮》中文书名号包裹
- "建立一美之阶梯"、"沿梯而上"、"朝向美之攀登"——古典节奏("之")
- "然则"、"毋宁"——文言连接
- 无翻译腔、无网络语

# 失败案例(已知 AI 错误)

### F-1 · 术语过度汉化

**症状**:把 *Eros* 译为"爱神"、把 *Heidegger* 译为"海德格尔"。

**修正**:术语保留铁律,括注统一。汉名(海德格尔)可在首次出现加括号,后续一律用 *Heidegger*。

### F-2 · 古典节奏失控

**症状**:全文用"之乎者也",译成古文。

**修正**:古典节奏是"之"与"于...之中",不是彻底文言。校读白话标准:每位中文母语者读得通。

### F-3 · 概念加粗泛滥

**症状**:每句都有几个加粗词,失去索引功能。

**修正**:加粗标准:概念重复出现 ≥ 3 次 + 是论证支点。每章加粗词 ≤ 15 个为宜。

### F-4 · 翻译腔

**症状**:"根据 Han 的观点,美本身……" / "在某种程度上,美是一种……"

**修正**:直接陈述:"Han 曰,美本身……" 或 "美乃……"。

### F-5 · 漏术语

**症状**:把希腊文 *thaumaston kalon* 译成"奇妙的美"而不保留希腊字。

**修正**:术语表强制,首次出现必须带希腊文 + 中文括注。
