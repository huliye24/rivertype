# Prompt · annotate(校注)

> 用途:为原文中的关键字词生成 `annotation` 区段。

---

## Prompt 模板

```text
你正在按 RiverType Transliteration Protocol (RTP) v0.1 为一段古籍原文添加校注。

# 任务

为以下 source 区段的**关键术语 / 生僻字 / 典故 / 通假字**生成 `annotation` 区段。

# 原文

<粘贴 source 区段>

# 校注五类(必须明确类型)

| 标记       | 适用                       | 示例                           |
|----------|--------------------------|------------------------------|
| `@校勘`   | 异文、讹误、脱衍                | "@校勘 此处帛本作'堇',王弼本作'若'。" |
| `@音注`   | 生僻字读音、通假字              | "@音注 恶,音'污'wù。"           |
| `@训诂`   | 字义、引申义                  | "@训诂 '德'字,引申义为'道之显化'。"  |
| `@字源`   | 汉字形体演变                  | "@字源 '德'字,从'彳'从'心',会意。" |
| `@出注`   | 引文出处、互证                 | "@出注 此句见《庄子·齐物论》。"       |

# 校注格式(严格)

```markdown
- **<章>.<字> <汉字>**:@<类型> <校注内容> [@<类型2> <更多>]
```

# 引用规则

- **任何引文必须给出处** — 如"@王弼《老子注·第 X 章》"
- **不要自创校注** — 王弼没说过的话不能挂王弼名下
- **不熟悉的不要强写** — 用 `[@?未知,待考]` 标记

# 反例

❌ "@王弼 此句含义深奥" — 王弼没说这话,自创
❌ "1.1 上:大也" — 缺 `@训诂` 标记
❌ "上 = 至极" — 没用 Markdown 列表格式
❌ 校注超过原文 5 倍长度 — 违反"不喧宾夺主"原则

# 输出格式

```markdown
<!-- @section: annotation -->
## 校注

- **1.1 上**:@训诂 大也,至极之名。@出注 王弼《老子注》:"上者,至极之名。"
- **1.3 若**:@音注 音"弱"ruò。@训诂 似也。
- **1.10 物**:@训诂 万物也。
```

# 校验清单

- [ ] 每条校注都有 `@类型` 标记
- [ ] 引用必须给文献出处
- [ ] 行号格式 `<章>.<字>` 与 source 对应
- [ ] 校注长度不超过原文 5 倍(否则拆出 `@延伸`)
```

## 实测案例

### 输入

```
> 上善若水。水善利万物而不争,处众人之所恶,故几于道。
```

### 输出

```markdown
<!-- @section: annotation -->
## 校注

- **1.1 上**:@训诂 至极、最上。@出注 王弼《老子注》:"上,至极之名。"
- **1.2 善**:@训诂 善于、擅长。@出注 河上公《老子注》:"善者,神明之德。"
- **1.3 若**:@音注 音"弱"ruò。@训诂 似、像。
- **1.6 水**:@训诂 水之德,柔弱不争。@字源 金文"水"象水流之形。
- **1.8 利**:@训诂 利益、利于。@出注 王弼:"利物而无择。"
- **1.10 万**:@字形 帛书作"萬",王弼本作"万",繁简之别。
- **1.13 恶**:@音注 此处音"污"wù,下、低之意。与"善恶"之"恶"è 不同。@训诂 厌恶。
- **1.15 几**:@音注 音"机"jī。@训诂 接近。
```

## 失败案例

### F-1 · 引用伪造

**症状**:AI 给出"@朱熹 此句论及格物致知"——但朱熹注的是《大学》,不是《老子》。

**修正**:Prompt 强调"引用必须真实,不确定用 [@?未知,待考]"。

### F-2 · 校注过度解释

**症状**:对每个字都给出三种训诂、五个出处,校注超过原文 10 倍。

**修正**:Prompt 限制"每字最多 3 类校注,优先选最权威者"。

### F-3 · 校注与白话重复

**症状**:白话区说"最高的善",校注区也说"上者,至高也",内容重复。

**修正**:Prompt 明确分工——"白话区不解释字义,只翻译句意;校注区解释字义"。

### F-4 · 行号错位

**症状**:原文是"上善若水",校注用 `1.4` 标注"水"字,但实际"水"是第 4 个字——这没问题;但如果用 `1.5` 标注,就是行号错位。

**修正**:校验器应强制校验行号。
