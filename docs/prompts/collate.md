# Prompt · collate(校勘异文)

> 用途:对比底本与参校本的字句差异,生成 `variants` 区段。

---

## Prompt 模板

```text
你正在按 RiverType Transliteration Protocol (RTP) v0.1 校勘一段古籍的异文。

# 任务

对比以下版本,生成 `variants` 区段的异文表。

# 底本

<底本全文>

# 参校本

- <参校本1 名称>:<全文>
- <参校本2 名称>:<全文>
- ...

# 校勘规则

1. **逐字比对** — 不要跳过任何字
2. **行号格式** — `<章>.<字序>`,从 `1.1` 开始
3. **异文类型**:
   - `@字形` 繁简、异体字
   - `@讹误` 字形讹误
   - `@脱文` 某版本缺字
   - `@衍文` 某版本多字
   - `@倒文` 文字顺序颠倒
   - `@通假` 字被借用
4. **校勘判断** — 给出底本选择理由(底本更优 / 参校本更优 / 难断)

# 输出格式

```markdown
<!-- @section: variants -->
## 异文

| 章·字 | <底本列名> | <参校1列名> | <参校2列名> |
|-------|----------|-----------|-----------|
| 1.1   | <底本字>   | <参校1字>  | <参校2字>  |
| 1.2   | ...      | ...       | ...       |

@校勘 <异文类型> <异文说明> <取舍判断>
```

# 反例

❌ 列名用 "版本1"、"版本2" — 必须用参校本简称
❌ 行号用 "第一行第一字" — 必须用 `1.1` 格式
❌ 不给校勘判断 — 必须说"底本从之"或"参校从之"
❌ 跳过无差异的字 — 仍要列出,或写"诸本同"

# 校验清单

- [ ] 异文表所有列名与 frontmatter `editions.collated` 一致
- [ ] 所有 `章.字` 引用都对应 source 区的字
- [ ] 每个异文都有 `@校勘` 说明
- [ ] 校勘判断给出依据(底本更优?早期本更优?出土本更优?)
```

## 实测案例

### 输入

**底本(王弼本)**:

> 上善若水。

**参校本(帛书甲本)**:

> 上善堇水。

### 输出

```markdown
<!-- @section: variants -->
## 异文

| 章·字 | 王弼 | 帛甲 |
|-------|------|------|
| 1.1   | 上   | 上   |
| 1.2   | 善   | 善   |
| 1.3   | 若   | 堇   |
| 1.4   | 水   | 水   |

@校勘 1.3 字形异文。"若"字,王弼本、通行本用"若";帛书甲本用"堇"。
@训诂 "堇"通"僅",意为"仅、几乎",与"若"义近。
@判断 帛甲本出土更早,字形保留古义。本项目以**帛甲本为底**,王弼本作参校。
```

## 失败案例

### F-1 · 跳过"无差异"字

**症状**:只列出异文字,其他位置留空。

**修正**:Prompt 要求"逐字列出",即使相同也列出,或集中写"诸本同"。

### F-2 · 校勘判断武断

**症状**:AI 给"@判断 底本更优"——但没说为什么。

**修正**:Prompt 要求"判断必须给依据(底本更早?学界共识?上下文契合?)"。

### F-3 · 列名与 frontmatter 不一致

**症状**:frontmatter 写 `河上公注本`,异文表写"河上"。

**修正**:校验器强制"列名 == frontmatter 中的字符串"。
