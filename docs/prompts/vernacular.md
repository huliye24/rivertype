# Prompt · vernacular(白话译)

> 用途:把古汉语原文转写为现代汉语白话。

---

## Prompt 模板

```text
你正在按 RiverType Transliteration Protocol (RTP) v0.1 把一段古汉语译为现代汉语白话。

# 任务

为以下原文生成 `vernacular` 区段。

# 原文(source 区段)

<粘贴 source 区段>

# 已知白话参考

<如有王力、郭锡良等通行译本,提供;如无,写 "无,需自行翻译">

# 白话译原则(三大铁律)

## 信(dengxin / fidelity)
- 不增不减,逐句对应
- 不擅自补充原文字面之外的内容
- 不擅自删除原文中看似"重复"的句子

## 达(smoothness)
- 现代汉语口语(普通话)
- 不用文言词("之、乎、者、也、矣"不应出现)
- 不用翻译腔("在某种程度上" 这种)

## 雅(elegance)
- 保留原文的庄重感或节奏
- 不用网络流行语
- 不用娱乐化表达

# 输出格式

```markdown
<!-- @section: vernacular -->
## 白话

<逐句翻译,每句一行,用 `>` 引用块>
```

# 反例(绝对不能这样译)

❌ "最高的善,犹如水之性,水能利益万物,而与万物无争。" —— "之"是文言词,不能用
❌ "水非常棒,它能帮助万物。" —— 过度意译,失去经文庄重
❌ "道可道,非常道。" —— 这是原文,不是白话
❌ "在某种意义上,道是可以被言说的,但被言说的道,就不再是恒常的道。" —— 翻译腔

# 正确案例

✅ "最高的善像水一样。水善于利济万物而不与之争夺,处身于众人所厌恶的低下之处,所以最接近于'道'。"

# 校验清单

- [ ] 逐句对应原文,不增不减
- [ ] 现代汉语口语,无文言词
- [ ] 保留原文庄重感
- [ ] 关键术语首次出现时保留原字:`道(dào)`
- [ ] 不在白话区放校注(放 annotation 区)
```

---

## 实测案例

### 输入

```
> 道可道,非常道;名可名,非常名。
```

### 输出

```markdown
<!-- @section: vernacular -->
## 白话

> 可以言说的"道",就不是恒常的"道";可以命名的"名",就不是恒常的"名"。
```

注意:

- "道"字保留并注音(dào)
- 逐句对应,未增减
- 无文言词("之、乎")
- 无翻译腔

---

## 失败案例

### F-1 · 网络流行语

**症状**:"道可道,非常道" → "道,说道,不太道"。

**修正**:Prompt 强调"严肃性",列举禁用语。

### F-2 · 文言残留

**症状**:"最高的善,乃如水也。" —— "乃"、"也"是文言词。

**修正**:Prompt 强调"现代汉语口语",列出禁用文言词清单。

### F-3 · 翻译腔

**症状**:"在某种意义上,水具有某种特殊的品质。"

**修正**:Prompt 列出翻译腔特征:

```
# 翻译腔特征(出现即重写)
- "在某种意义上" / "在某种程度上"
- "具有某种" / "某种特殊的"
- "令人感到" / "给人以"
- "...的体现" / "...的反映"
- 被动句过多
```

### F-4 · 术语过度意译

**症状**:"道"译成"宇宙规律","德"译成"品德"。

**修正**:Prompt 要求关键术语保留原字,术语表见 `docs/GLOSSARY.md`。
