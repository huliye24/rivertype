# Prompt · punctuate(断句)

> 用途:给原文加现代标点,并说明断句依据。

---

## Prompt 模板

```text
你正在按 RiverType Transliteration Protocol (RTP) v0.1 给一段古籍原文加现代标点。

# 任务

为以下 .rt 文件的 `punctuation` 区段,输出断句与依据。

# 原文(source 区段)

<粘贴 source 区段内容>

# 已知断句候选

<如有多种断句候选,列出;如无,写 "无,需自行判断">

# 断句规则

1. **优先采用学界共识** — 王力《古代汉语》、郭锡良《古代汉语》等
2. **并列保留** — 同一原文有多种合理断句时,主区放主流断句,`<!-- @alt: punctuation -->` 区放其他候选
3. **每处断句必须有依据** — `@校断` 标记 + 出处

# 输出格式

```markdown
<!-- @section: punctuation -->
## 断句

<加完标点的原文,用 `>` 引用块>

@校断 <你的断句依据,如"依王力《古代汉语》校注本"或"依帛书甲本断句"。

<!-- @alt: punctuation -->
## 断句·候选

<其他合理断句,如有>

@校断 <依据>
```

# 反例

❌ 不给依据:"道可道,非常道。" —— 必须说明断句方式
❌ 自行造断:"道,可道,非常道。" —— 改了原文标点位置不说理由
❌ 把所有古籍都断成短句 —— 应反映文体节奏(散文 vs 骈文 vs 韵文)

# 校验清单

- [ ] 原文一字不改,只加标点
- [ ] `@校断` 给出处
- [ ] 多种断句用 `@alt` 区
- [ ] 标点密度反映文体(韵文断长,散文断短)
```

---

## 实测案例

### 输入

```markdown
<!-- @section: source -->
## 原文

> 道可道非常道
> 名可名非常名
> 无名天地之始
> 有名万物之母
```

### 输出(正确)

```markdown
<!-- @section: punctuation -->
## 断句

> 道可道,非常道。
> 名可名,非常名。
> 无名,天地之始;
> 有名,万物之母。

@校断 依王力《古代汉语》通行断句。

<!-- @alt: punctuation -->
## 断句·候选

> 道可道,非,常道;名可名,非,常名。

@校断 严灵峰《老列三篇知新录》持此说,以"非常"为"非+常"。
```

## 失败案例

### F-1 · 改字不加标点

**症状**:AI 把"可道"改成"可,道"——错。

**修正**:Prompt 强调"只加标点,不改字"。

### F-2 · 不断句只解释

**症状**:AI 输出"道可道'意谓可以言说之道',非常道'意谓非常恒之道'"——这是注释,不是断句。

**修正**:Prompt 区分"断句(punctuation)"和"校注(annotation)"。

### F-3 · AI 忽略韵文

**症状**:把《楚辞》当散文断,标点过密,失去韵律。

**修正**:在 Prompt 中加文体判断步骤:

```
# 文体判断

原文是散文 / 骈文 / 韵文 / 诗?
- 散文:标点可密
- 骈文:四六句为主,标点反映对仗
- 韵文:每句一标,句末标点,标点体现韵脚
- 诗:每句独立,基本不跨句
```
