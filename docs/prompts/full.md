# Prompt · full(一键转译全流程)

> 用途:让 AI 一次完成"转录 → 断句 → 校勘 → 校注 → 白话 → 英译"全流程。

---

## Prompt 模板

```text
你正在按 RiverType Transliteration Protocol (RTP) v0.1 一次性转译一段中国古籍。

# 任务

输出以下 `.rt` 文件,包含全部区段:
- `source`(原文)
- `punctuation`(断句)
- `variants`(异文)
- `annotation`(校注)
- `vernacular`(白话)
- `english`(英译)
- `meta`(元信息)

# 输入信息

## 待转录文本

<原始文本 / OCR 文本 / 扫描件 OCR 结果>

## 底本与参校本

- 底本:<底本名称>
- 参校本 1:<名称 + 文本>
- 参校本 2:<名称 + 文本>

## 元信息

- 书名:<书名>
- 作者:<作者>
- 朝代:<朝代>
- work_id:<work_id>
- 转译引擎:<如 "文川院 AI v1">

# 全流程规则(强制)

## 转录阶段
- 一字不改,异体字 / 避讳字保留
- 看不出的字用 `[?]`

## 断句阶段
- 依据学界共识
- 多种断句用 `<!-- @alt: punctuation -->` 区

## 校勘阶段
- 逐字比对所有版本
- 异文用表格
- 每条异文给 `@校勘` 判断

## 校注阶段
- 五类校注:`@校勘` `@音注` `@训诂` `@字源` `@出注`
- 引用给文献出处
- 不熟悉的用 `[@?未知,待考]`

## 白话阶段
- 信达雅
- 现代汉语口语,无文言词
- 关键术语首次出现保留原字

## 英译阶段
- 关键术语保留原字 + 拼音
- 不强行押韵

# 输出格式(严格)

输出一个完整的 .rt 文件,严格按 RTP-0.1 规范。完整规范:https://github.com/huliye24/rivertype/blob/main/docs/protocol/RTP-0.1.md

# 失败模式警告(已知)

⚠️ 不要补出原文没有的字
⚠️ 不要自创校注引用
⚠️ 不要把避讳字"还原"
⚠️ 不要把白话写成文言
⚠️ 不要跳过异文比对
⚠️ 不要把术语过度意译

# 校验清单(自检)

- [ ] frontmatter 9 个必需字段齐全
- [ ] 所有区段按顺序存在
- [ ] 异文表列名与 frontmatter 一致
- [ ] 校注行号与 source 对应
- [ ] 白话无文言词
- [ ] 英译术语保留原字

# 提示

如某区段无法完成(如只有一个版本,无法做异文),在该区段写明"无参校,无法对比",不要省略区段或虚构内容。
```

---

## 使用场景

**适用**:

- ✅ 单一文本首次完整转译
- ✅ 一本书的一章、一节
- ✅ 短篇完整古籍(如《心经》260 字)

**不适用**:

- ❌ 长篇多卷古籍(分章调用此 Prompt,避免上下文过长)
- ❌ 需要多轮校对的复杂文本
- ❌ 学界争议大、需专家介入的文本

---

## 风险

一键转译**永远不如分步转译准确**。分步转译允许人工在每一步检查,一键转译把风险押在 AI 一次输出上。

**建议**:

- 一键 Prompt 用于**快速预览**
- **正式发布**前,走分步 Prompt(transcribe → punctuate → collate → annotate → vernacular → english),每步人工复核
